# Cirkel-flow handoff log

Working companion to `circle-arc-automation-brief.md`. The brief is the static
scope document — this file tracks decisions, unresolved questions, and known
limitations as they land.

## Confirmed workflow

1. Welcome → **Verwerk cirkel…** button.
2. Pick document (existing `pickDocument()` dialog).
3. Pick shape: **Behangcirkel (BC, 10 mm bleed)** or **Muursticker (MS, 3 mm bleed)**.
4. If the master is Duotone, show the Dutch notice and convert the working
   duplicate to Grayscale + `Gray Gamma 1.0`. The master on disk is never touched.
5. Flatten + detect circle (largest non-white region).
6. Match measured Ø against the catalog set for the chosen shape.
   - Single match → preselect.
   - Multiple within 15% → Dutch picker ("Gemeten: 152 cm cirkel. Bedoel je
     142,5 cm of 190 cm?").
   - No detection → manual size picker as fallback.
7. Confirm dialog: abbreviation (editable, prefilled from filename), size list,
   final canvas sizes, output dir preview.
8. Export loop: for each catalog Ø, duplicate working doc, resize content to
   target Ø, expand canvas with bleed (centred, white fill), assign Gray Gamma
   1.0, save TIFF, close duplicate.
9. Working duplicate closes without saving. Master PSD on disk is unmodified.

Output:

- `BC` → 4 TIFFs at 950 / 1425 / 1900 / 2375 mm + 2 × 10 mm bleed each.
- `MS` → 4 TIFFs at 300 / 1000 / 1200 / 1400 mm + 2 × 3 mm bleed each.
- Filename: `{ABBR}_{BC|MS}_{mm4}.tif` (4-digit padded mm).
- Output dir: `{master_dir}/{master_name}_export/`.

## Catalog source-of-truth decision

**Option A — build-time codegen** (brief §3.6).

`scripts/gen-config.py` reads `../../wallgen/var/catalog/dimensions.json` and
emits `src/modules/config-generated.jsx` (gitignored, regenerated by every
build). `config.jsx` retains DPI, bleed, ICC, rectangle/drieluik constants
only — those are tool-internal and not derived from wallgen's catalog.

BC vs MS partitioning is by **explicit key set**, not value threshold:

- BC: `{D_0950, D_1425, D_1900, D_2375}`
- MS: `{D_0300, D_1000, D_1200, D_1400}`

`gen-config.py` fails loud when wallgen adds a new diameter key — better than
silently sliding it into the wrong shape bucket. To add a new size, update both
wallgen's catalog and the key set in `gen-config.py`, then rebuild.

`ARC_W_MM` / `ARC_H_MM` come from the `W_ARC` / `H_ARC` entries in widths/heights.

## Detection contract

**Resolved this session — auto largest-non-white-region only.** No named
mask, no `cirkel` layer convention. Implemented as Action Manager Color Range
sampled on white (luminance 100), inverted to capture every non-white pixel,
read `doc.selection.bounds` as the bounding box, and treat it as the circle's
bbox. Centre = bbox centre, radius = max(half-width, half-height).

### Known limitations

- **Off-centre circles** → bbox centre lies off the design centre.
  `resizeContentToDiameter` still hits the right Ø (it scales the whole doc),
  but the bleed gets anchored on the document centre, not the design centre.
  Mitigation: scope is mono masters that are roughly centred. If Inge sees
  visibly off-centre output, log and switch to a layer-mask convention.
- **White-as-design** (logo on a white inner shape) → Color Range can't
  distinguish design-white from background-white. Mitigation: detection runs
  *before* any white background insertion, so source-supplied white still
  reads as background.
- **Stray non-white pixels outside the circle** (artist marks, residual text)
  → inflates the bbox and overshoots the catalog match. Mitigation: confirm
  dialog before export gives Inge a chance to bail.
- **Fully white source** → `doc.selection.bounds` throws; `detectCircle()`
  returns `null`. The flow falls back to a manual size picker.

### ExtendScript surprises encountered

- `executeAction("assignProfile")` is the only path that survived in the
  existing tool — used in `assignGrayGamma()` to satisfy the Gray Gamma 1.0
  contract after `changeMode(GRAYSCALE)`.
- `Color Range` via the action manager needs `colorModel: false` and Lab
  sample values `{L:100, a:0, b:0}` — sampling RGB white at fuzziness 0
  occasionally caught antialias edges, so fuzziness 5 + invert is what made
  detection consistent.
- `doc.selection.bounds` throws if the inversion produced no selection
  (fully white doc). Wrapped in try/catch and surfaced as a manual-size
  fallback rather than a crash.
